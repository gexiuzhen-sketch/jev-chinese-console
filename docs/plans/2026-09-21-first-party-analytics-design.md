# Jev 中文体验台第一方统计设计

## 目标

在不引入第三方统计脚本、不保存用户输入与模型答案的前提下，统计朋友圈传播后的访问和试用效果。

## 指标

- PV、UV、今日活跃访客、近 7 日活跃访客
- Jev 判断次数、成功率、使用转化率、平均响应时间
- Noul / Choice / Score 使用分布
- 示例点击、判断类型切换、首屏 CTA 点击
- 注册与登录成功次数
- 按天趋势

## 数据设计

浏览器首次上报时由服务端设置随机、HttpOnly、SameSite=Lax 的匿名访客 Cookie。数据库只保存该随机值的 HMAC 哈希，不保存原值或原始 IP。事件表只接受服务端白名单事件，并仅保存事件类型、允许的维度、数值、日期和时间。

Jev 输入内容、判断问题、候选选项、模型答案、邮箱与密码均不进入统计表。事件默认保留 90 天，定时清理。

## 安全

统计看板数据接口要求独立的 `ANALYTICS_ADMIN_TOKEN`，使用 Bearer Header 传输并进行恒定时间比较。接口启用频率限制与 `Cache-Control: no-store`。管理口令不进入仓库、URL或浏览器持久存储，只在当前标签页会话中保存。

## 页面

`/analytics.html` 提供只读中文看板，包括核心指标卡片、每日趋势、判断类型分布和互动漏斗。无管理口令时仅显示解锁表单。
